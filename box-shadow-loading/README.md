# Box Shadow Loading 动画效果

这是一个使用 **HTML + CSS** 实现的加载动画（Loading Animation）示例。  
通过 **CSS 动画（@keyframes）+ box-shadow + transform**，实现具有节奏感和空间感的柱状加载效果。

---

## 📸 效果说明

- 多个竖向柱状条依次运动
- 通过 `animation-delay` 形成波浪式动画
- 利用 `box-shadow` 增强立体感
- 使用 `opacity + scale + translateX` 增强动效层次

非常适合用于：
- 页面加载中（Loading）
- 数据请求等待
- 后台管理系统
- 可视化大屏

---
